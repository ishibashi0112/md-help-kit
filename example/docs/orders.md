# 受注一覧

受注を探して、状態をまとめて更新する画面です。

## 絞り込み

表の上の欄に、受注番号か顧客名の一部を入れます。一致する行だけが表示されます。

## 一括更新

1. 更新したい行のチェックボックスを選びます
2. 「一括更新」を押すか、<Shortcut keys={["Ctrl", "E"]} /> を押します
3. 変更後の状態を選んで、「保存」を押します

> [!WARNING]
> 完了済みの行は変更できません。選択に含まれている場合、その行だけ更新されずに残ります。

状態の移り変わりは、[図の見本](diagrams.md#受注の状態)にまとめています。

出荷の前に、在庫が足りるかを[在庫照会](stock.md)で確かめてください。
